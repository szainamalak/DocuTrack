# DocuTrack Pro
Upgraded document expiry tracker with browser notifications, PWA/service-worker support, and an optional Node.js Web Push backend.

Reminder checkpoints: 7 days, 3 days, 2 days, 1 day, and expiry day.

For an IDT demo: open the site over HTTPS/localhost, press 🔔 and allow notifications, then use Load Demo Data.

Important: a static GitHub Pages site cannot guarantee a future notification while the browser/device is completely inactive. The included push server is the production-style solution for guaranteed scheduled Web Push.
